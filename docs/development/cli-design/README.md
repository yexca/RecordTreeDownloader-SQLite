# CLI Design Documents

These documents describe the design and implementation plan used for the CLI-oriented version of RecordTreeDownloader SQLite.

They are development documentation, not user instructions. Current user-facing documentation lives under `docs/user-guide/`, and current maintainer documentation lives under `docs/maintainer-guide/`.
